# Automatizacija transportne trake sa stanicom za vaganje proizvoda

Diplomski projekat u CoDeSys/CODESYS okruženju.

## Opis

Projekat predstavlja automatizovanu transportnu i sortirnu liniju sa stanicom za vaganje proizvoda. Sistem obuhvata ulaznu transportnu traku, mernu stanicu, sortirnu traku, pneumatske izbacivače i akumulacione zone za proizvode različitih masa.

## Struktura projekta

- `Codeys/` - CoDeSys projekat i eksportovani POU blokovi
- `Dijagrami/` - blok dijagrami, state machine i ostale šeme
- `Dokumentacija/` - radna dokumentacija i specifikacija sistema
- `PDF izvestaji/` - PDF verzije izveštaja i I/O liste
- `Simulacija/` - test scenariji i rezultati simulacije

## Tehnologije

- CoDeSys 2.3
- Structured Text
- PLC simulacija preko SP PLCWinNT
